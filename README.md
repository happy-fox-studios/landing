Полная копия сайта с Тильды (снята 28.10.2026). Все картинки, стили и скрипты лежат в `assets/`, к серверам Тильды сайт не обращается.

Попапы проектов (Atlantida, Urban Samurai, Hell Battler и др.) находятся внутри страниц и работают.

## Как выложить

1. Создайте репозиторий на GitHub и загрузите в его корень **всё содержимое этой папки**, включая скрытый файл `.nojekyll`.
2. В репозитории откройте Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Свой домен: в файле `CNAME` уже указан `happyfoxstudios.com`. После переключения DNS включите в Settings → Pages галочку *Enforce HTTPS*.
   DNS у регистратора:
   - `A` записи для `happyfoxstudios.com`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www`: `<ваш-логин>.github.io`

   Чтобы сначала проверить сайт по адресу `логин.github.io/репозиторий/`, удалите файл `CNAME`. Все пути относительные, поэтому сайт откроется и там. Исключение — страница 404: её пути рассчитаны на корень домена.

`.nojekyll` обязателен: без него GitHub Pages пропустит файлы, имена которых начинаются с `_`.

## Что работает иначе, чем на Тильде

- **Формы удалены.** Секция CONTACT US с формой (на всех страницах) и форма «Join us» на `/about` отправляли заявки на сервер Тильды, поэтому их убрали целиком. Кнопка CONTACT US в шапке и пункт JOIN US теперь прокручивают к футеру, где указана почта happy@happyfoxstudios.com. Чтобы вернуть форму, понадобится сторонний обработчик (Formspree, Web3Forms, Getform).
- **Каталог на /our-portfolio/**. На живом сайте он был пуст (показывал «Nothing found»), и в копии так же. Ответы API сохранены в `assets/store/`.
- **Статистика Тильды** отключена. Google Analytics / Tag Manager (G-7DY82TSLXQ) продолжает работать.
- **Внешние ресурсы**, которые остались по ссылкам: шрифты Google Fonts и Adobe Typekit (`use.typekit.net/alb2gij.js`), видео с Dropbox, ссылки на ArtStation и Steam. Typekit привязан к вашему аккаунту Adobe и списку доменов: если домен останется тем же, шрифты продолжат грузиться.

## Технические детали

- `assets/static/`, `assets/thb/`, `assets/neo/` — файлы с CDN Тильды (static/thb/neo.tildacdn.com), пути сохранены.
- `assets/vendor/jquery-1.12.4.min.js` — jQuery, раньше грузился с cdnjs.
- В `<head>` каждой страницы добавлены заглушки для служебных функций Тильды (переключение на зеркала CDN, отчёты об ошибках). В `our-portfolio` также добавлен перехват запросов каталога к локальным JSON.
- Картинки отдаются в исходном формате. Тильда на лету конвертировала их в WebP, поэтому страницы стали немного тяжелее.
